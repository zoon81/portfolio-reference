# Project photos

Use this folder for the real device and PCB photos when they are ready.

| Suggested filename | Where to use it |
| --- | --- |
| `assembled-handheld.jpg` | Main README image, with the display and keypad visible |
| `main-board-front.jpg` | Hardware section, alongside the schematic and render |
| `main-board-back.jpg` | Hardware section, with the component side visible |
| `keypad-board.jpg` | Optional close-up of the separate keypad PCB |

Export JPEGs around 1600 pixels on the long edge and check the crop at
README size. Check the scene for customer branding and serial labels, then
remove location metadata from the exported images before committing.

To feature the assembled device, add the photo here and update the first
image in the root README.

```html
<img src="assets/photos/assembled-handheld.jpg" width="720" alt="Assembled handheld with its screen and keypad visible">
```

The enclosure render can then sit in the hardware and enclosure section.
